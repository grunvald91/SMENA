# Публичный адрес `smena.servgo.ru`

**Статус: проектирование; не опубликовано.**

1. DNS: добавить A/AAAA/CNAME согласно фактическому способу размещения (сейчас целевой хост не задан); настроить TLS.
2. Веб-интерфейс Mini App уже реализует: таблицу смен, расписание по датам, обзор, начисления, аналитику и CSV.
3. `Telegram.WebApp.Serverless.call` проверяет Telegram Mini App initData на платформе. Внешний сайт не получает эту авторизацию сам по себе.
4. На стороннем домене сейчас допустима **публичная страница без персональных сведений**. НЕ копировать salary API и `ctx.initData.user` в браузер как доверенный идентификатор.
5. Для **полноценного самостоятельного кабинета в браузере** нужны отдельный backend, Telegram OIDC/Login или проверенная сервером подписанная сессия, tenant isolation, CSRF, лимиты, аудит и единый источник данных с ботом. Хранилище Serverless SQLite нельзя считать напрямую доступным VPS.
6. Продакшен-запуск: выполнить dry-run миграций, E2E внутри Telegram, настроить BotFather Main Mini App, затем проверку на телефоне, проверку доступа и домена.
7. В рабочей группе `/bind Название точки` выполняет владелец-администратор группы; `locations.chat_id` однозначно привязывает чат к точке. Фото направляются туда через `api.sendPhoto`.

Не использовать вымышленные реквизиты хостинга/бота, пока они не получены и не проверены.
