# Кнопочный мастер ServGo Смена — переходный этап

## Изменения
- /start показывает Telegram reply keyboard: «Создать бизнес» (если бизнеса нет) или «Подключить группу», «Сотрудники», «Отчёт», «Кабинет».
- Кнопка «Создать бизнес» → запрос названия → старая безопасная функция setup.
- «Подключить группу» → официальный Bot API request_chat (группы, где бот состоит участником) → chat_shared. Сопоставляются request_id, TTL 15 минут и Telegram ID владельца. Сервер заново получает getChat/getChatMember и проверяет право администратора и возможность публикации фото до bindChat.
- /setup и /bind остаются резервными путями; работающий kiosk / QR / фотоконтроль не меняется.
- Устройство на точке не требует камеры; Telegram Serverless не подключается напрямую к VPS ServGo.
- Бот использует только update типа message, поэтому старый allowed_updates=message остаётся совместимым.

## Пока не реализовано
- Множественные бизнесы у одного владельца: owner_tg_id всё ещё unique и старые owner-only функции используют legacy контекст. Изменение будет отдельной проверенной миграцией.
- Приглашение сотрудников и синхронизация с booking_bot.
- Испытания нового интерфейса на живом Telegram и обновление production.

## Проверки до выпуска
1. npm run check, npm run build в Codespaces; tgcloud migrate --dry-run --local.
2. Проверенный бэкап существующей базы и пробное восстановление.
3. Новый пользователь: создать бизнес кнопками, повторное создание отклоняется.
4. Владелец: выбрать группу, получить chat_shared, привязать точку. Повторный и чужой request_id не принимаются.
5. Бот без доступа, пользователь без статуса администратора, группа, привязанная к другому бизнесу — отказ без побочных изменений.
6. Ничего не меняется в старых /setup, /bind, QR, selfie, отчётах, фотографии и комментарии; проверка на реальных телефонах.
